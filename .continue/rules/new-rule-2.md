# Enforce RUFF Compliance for Python

✅ Linting Rules

Enforce all enabled RUFF rules, including but not limited to:

Syntax correctness

Formatting (whitespace, line length)

Naming conventions (variables, functions, classes)

Complexity and code smells

Import sorting and style

Type hint usage and annotations

✅ Style and Formatting

Ensure spacing, indentation, and line breaks follow RUFF defaults or project-specific overrides.

Respect line length limits as configured.

Use consistent quote styles and trailing commas per RUFF rules.

✅ Import Handling

Apply RUFF’s import sorting and grouping logic (e.g., standard library, third-party, local imports).

Use absolute or relative imports consistent with the project and RUFF settings.

✅ Type Hints

Include or omit type hints as enforced or suggested by RUFF configurations.

Use modern syntax supported by the project’s Python version.

✅ Integration with Project Configuration

Respect .ruff.toml, pyproject.toml, or other config files that customize RUFF’s behavior.

✅ Error-Free Code

Generated Python code must pass RUFF checks with zero errors or warnings.
